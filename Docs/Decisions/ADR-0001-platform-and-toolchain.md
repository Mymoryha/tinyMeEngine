# ADR-0001：单开发机平台与工具链

- 日期：2026-11-05
- 状态：Accepted
- 关联任务：M0-001、M1-001

## 背景

个人渲染研究项目，仅计划 Windows，目标体验和结构合理性而非多设备覆盖。实测主 GPU 是 RTX 5080，已有 VS2022 C++ 工具和 Windows SDK。所有者未指定图形 API。

## 选项

- D3D12：Windows 原生，现代显式 GPU 模型，适合学习资源/barrier/队列和前沿特性；初始生命周期工作较多。
- Vulkan：覆盖更多平台，但本项目目前不需要这些收益，会增加工具和适配负担。
- D3D11：首帧简单，但后续显式 GPU 管理与现代能力研究可能需要迁移。

## 决定

以 Windows 11 x64 / RTX 5080 为开发验收基线，首个且唯一后端选 D3D12；此为工程默认选择，不声称用户曾明确指定 API。使用 C++20、VS2022 v143、CMake 3.31.10、SDK 10.0.26100.0。HLSL/DXC 在首次 shader 任务时引入并固定版本。

CMake 使用 VS2022 multi-config generator，可从普通 PowerShell 构建，不额外要求 Ninja 或手工开发者环境。构建工具可本地隔离安装；配置期不联网。

## 代价与约束

不支持非 Windows、其他 GPU 回归、多后端和低配降级。平台限制只写在平台/构建边界，核心逻辑仍保持纯 C++ 以利测试，并不因此创建跨平台接口。

RTX 5080 的具体特性由 D3D12 查询决定，不能以型号推断启用。保留集显但不作为渲染目标。

## 验证

M0 验证编译器/SDK、Debug 和 RelWithDebInfo 构建。M1 枚举 adapter、记录真实 feature 支持、D3D12 清屏、窗口生命周期与验证层检查。

## 重审触发

真实实验受到 D3D12 或编译器限制；所需工具不支持当前版本；所有者明确改变平台目标。不可只因为“以后可能跨平台”推翻此决定。
